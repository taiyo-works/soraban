## 確認できなかった事項（未確認として扱う）

- **敷地形状。** 告示の区域図（PDF）と OpenStreetMap はいずれも作業環境から取得できなかった（区域図 PDF は画像でありトレースが必要。OpenStreetMap の Overpass API・Nominatim は robots.txt で拒否）。全施設を「中心点＋推定敷地半径」で保守側に判定し、判定の note に「敷地形状未収録のため概算」と出す。推定半径は確認値ではない。
- **美保基地の告示番号・高尾山分屯基地の告示番号。** 防衛省の報道資料で指定日と効力発生日は確認したが、指定告示の番号は資料に記載がなかった。
- **森山地区・島根原子力発電所の指定日と告示番号。** 警察庁の指定一覧で指定を確認したが、日付と告示番号は確認できなかった。
- **美保通信所の位置。** 美保基地に隣接（鳥取県警察）とされるが、隣接の方向と範囲を確認できなかったため収録していない。美保基地の推定半径（2,000m）が一部を覆うと考えられるが確認していない。
- 候補名は指定を意味しない。上表以外の施設（例：空港、国の重要施設等）は鳥取県・島根県で指定を確認していない。

## 更新手順

1. 鳥取県警察・島根県警察のページから各施設の区域図 PDF を取得し、敷地（赤枠）をトレースして `geometry` を `{ "type": "polygon", "rings": [[{"lat":..,"lng":..}, ...]] }` に置き換える。`geometrySource` に「告示区域図のトレース（PDF 名・取得日）」と書く。
2. OpenStreetMap を使う場合は `geometrySource` に OSM の way/relation ID を書き、地図・PDF に「© OpenStreetMap contributors, ODbL」を表示する。
3. `verifiedAt`・`verifiedBy` と、台帳 `../sources.json` の `small-drone-law-facilities.verifiedAt` を更新する（証跡 ID が変わる）。
4. `pnpm test` を実行する（全件に告示 URL・敷地形状の出典・確認日があることをテストで検査している）。
