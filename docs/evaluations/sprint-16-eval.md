# Sprint 16 評価：G-2（屋外の実機）の確認表

作成: evaluator、2026-11-26（16-N3 の評価の後。契約 `docs/sprints/sprint-16.md` の「G-2 で見る項目」G2-1〜G2-10、§17 の 11・13・21・23・30・31）。
**G-2 が済むまで Sprint 16 を完了にしない**（N-5）。この表は、ユーザーが屋外の実機で見るための手順。Chromium の自動操作では見えないもの（Safari の描画、直射日光、手袋、VoiceOver、実際の指のタップ）だけを集めてある。

## 1. 用意するデータ（空の環境の場合）

運航管理者のアカウントで、次を先に作っておく（本番ではなく、試験用の環境で行う）。

1. 機体 2 機、操縦者（本人のアカウントに結び付いたもの）1 名。
2. 今日の日付で、計画 2 件（13 時ごろ・16 時ごろ。題は長めに。例「橋梁の定期点検と河川敷の空撮の合同飛行」「午後の山あいの送電線の巡視撮影と周辺の確認」）。同じ日の別の計画のチップ（G2-4）が出る。
3. 氏名の長い操縦者 1 名（40 字ほど）と、技能証明の期限が 60 日以内のもの（ホームの「近づく期限」の対象が長くなる。G2-1・N3-8）。
4. 端末に送信待ちが 1 件ある状態（現場で、機内モードにして「離陸」を押す。G2-2・ログアウトの確認の画面）。
