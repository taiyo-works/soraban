## C. 今回（B1・B2・N1〜N5 の修正）で変えたもの

### C-1 折りたたみに伴い、「開いてから見る・押す」に直したもの

`/` の規制カードの「根拠の詳細」、申請支援の「申請の準備」、収録の一覧は、見出しだけ見せて畳んだ（B2）。畳んだ中の部品は画面に見えず押せないので、見る・押す前に開く。文字の内容を読むだけの検査（`toContainText`）は、開かなくても通るので変えていない。検査する内容は同じで、開く 1 手を足しただけ。

### C-3 検査を弱めていない根拠

- 結論・手続き・規制ごとの判定の**文字の内容**を見る検査は、畳みの影響を受けない（`toContainText` は畳まれた中も読む）。変えたのは、畳まれた中の部品を**見る・押す**検査だけで、開く 1 手を足した。
- 判定の根拠・出典・確認日・免責は、畳まずに見える。規制カードの出典リンク・データの確認日・確からしさ・条文確認日、結論の「確認日」「出典つき」の札、結果と申請支援の免責は、畳んだ状態で `toBeVisible` を確かめる（B2 の新規テスト）。
- CLS のしきい値・コントラストのしきい値・タップ 44px のしきい値は、一切変えていない。

## D. 実装者の報告との差（評価 N9）

実装者の初回の報告にあった「旧版 約 21,000px」は再現できなかった。**同じ条件（375px・`next start`・米子市役所の自動判定が出た後）の main は 16,646px、PR ②（初回）は 20,202px で、初回の PR は main より長かった**。本修正の後（同条件）は **375px で 12,086px（main の 16,646px より 27% 短い）、1280px で 6,713px（main の 9,923px より 32% 短い）**。この条件は、画面を開いて米子市役所の自動判定が出た後（`scripts/` の測定と同じ）。
