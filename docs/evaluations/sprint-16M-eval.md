## 9. 申し送り（差し戻しではない）

1. **余裕が薄い**: Q-20 ③ 375 は 1,640／1,664px（24px）。公開 `/` の結論〜手続きの上に行や余白を足す担当（16-N を含む）は、先に `sprint12h-pr2` の Q-20 を流す。上限は上げない。
2. **未確認の総合の下の文**（16-M の外・planner）: 判定不能を含む計画で、総合は「未確認の項目があります（2 件）」だが、その下の説明は「手続きを済ませれば飛べます。下の手続きを期限までに済ませてください。」のまま（`VERDICT_HELP`、c3dfe5e から不変。`/ops` の `/judgement` で確認）。未確認の項目があるのに「飛べます」と読めるので、Q-L16 の質問票に入れて専門家の確認を取るのが安全側。確認が出るまで外部提供しない。
3. 全体の CLS（0.0002〜0.0011）は結果が出る分の小さなずれ。契約の「CLS 0」は header 内のずれ（`sprint11b` 3、通過）の意味で満たす。基準の値は測っていない。
4. 検証できなかったこと: 実機（G-2 は 16-N）、各状態での文字 200%（初期の状態だけ測定。`sprint16-m` K-5 は通過）、`sprint9` 306 の根本原因（既知の不安定。基準でも落ちる）。
5. ユーザー判断が要る点: なし（Q-L16 の専門家確認は planner 経由）。
