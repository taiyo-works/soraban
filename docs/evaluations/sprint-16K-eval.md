## 3. 不具合（要修正）

### R-1（中・designer）文字 200% で現場画面が横スクロールし、先読みの日時が切れる（共通条件 K-5 の退行）

- 原因: 状態の帯（`field-client.tsx` の `bandEl`）の「先読みの最終更新 01/05 12:00」の `<span className="whitespace-nowrap">`（designer の N-2「値（日時）は途中で折り返さない」）。200% では 1 つの塊のまま約 527px 幅になる。
- 再現: `html { font-size: 200% }` で、320・375・390 幅の `/ops/plans/<id>/field` を開く。実測 `documentElement.scrollWidth` は **527（clientWidth 320・375・390）**、はみ出す要素は `field-status-prefetch` と `SPAN`。390・430 幅で `measureTextZoom`（K-5 の helper）を使っても 527 > 390・430。新しい先読み（古くない）・オンラインでも同じ。`375-6-stale-200pct.png` は日付が「01/」で右に切れている。
- 切り分け: 注入 CSS で `.whitespace-nowrap` だけ外すと、375・390 で `scrollWidth` が幅と一致（0 件のはみ出し）。つまり原因は帯の `nowrap` で、基準（`nowrap` なし）では出ない（`*-6c-200-nowrap-off.png`）。320 の残り 368px（`field-back`・見出し）は帯と無関係で、`nowrap` を外しても残る既存の状態（K-5 の範囲外の 320）。
- 契約: K-5 は全画面の共通条件で、E2E にない画面も evaluator が測り、横スクロールがあれば不合格にできる（16-B 差し戻し 1 の R1-5）。16-K の `sprint16-k-db` は 200% を測っていないため E2E は通っている。
- 修正指示（designer）: 帯の「先読みの最終更新」と日時を別の `nowrap` の塊に分け（ラベルと日時の間で折り返せるようにする）、200% で最長の塊（日時 約 200px、ラベル 約 288px）が 390 幅に収まるようにする。等倍 320・375 の帯 ≤100px（92px）は保つこと。直したら `sprint16-k-db` に「200%・390・430 で `scrollWidth ≤ clientWidth`（帯が古い・新しいの両方）」を足し、旧コードで落ちることを確かめる（`measureTextZoom` を使える）。帯の高さの上限は変えない。

## 5. 意見（依頼 8・9）

- **8. 文字 200% の帯 227px（320×740 の約 3 割）**: 契約外で、高さだけなら申し送りで許容できる（sticky のまま 30% を占めるが、帯は 4 項目すべてが読める）。ただし**今回の 227px は横スクロールと日時の切れと引き換え**なので、そのままでは許容できず R-1 で不合格にした。R-1 を「折り返しを許す」で直すと 200% の帯は実測で 317〜362px（320 で 43〜49%）に伸びる。画面の半分近くを固定で占めるのは問題なので、R-1 と同時に「文字が大きいとき（高さが画面の 25% を超えるなど）は帯の sticky を外す」か、帯の項目を絞る案を designer が検討するのがよい。文字 200% の帯の高さは契約外なので、後者は申し送りで可（G-2 の実機で確認）。
- **9. 選択中の見た目（薄い面＋墨の太い縁＋太字＋◉）**: 良い。色なしでも縁の太さ・太字・記号で読め、主色の面は離陸・着陸だけになったので「主ボタン 1 つ」が見た目でも成り立つ。幅・高さは未選択と同じ（64px、`padding-inline` 補正で文字の位置が動かない）。懸念は 2 点だけ：(a) 面の色が薄い青（#E8F0FD）で日差しでは面の差が弱いが、縁・太字・記号が差を担うので問題なし。(b) 選択中が「押せる／押した」のどちらにも読めるが、◉/○ のラジオの慣習で読める。変更不要。

## 7. 検証できなかったこと

- 実機の日差し・端末の文字設定（G-2）。文字 200% は `html{font-size:200%}` の模擬。
- Service Worker の実際の更新（`pwa-update` の出現は E2E の発火で確認）。
- 基準 `1daf5fd` を再ビルドしての P3b2b-6・200% の直接比較は行っていない（P3b2b-6 は runbook の記録と HEAD の単独 4/4・ファイル 6/6、200% は `nowrap` を外す注入で切り分けた）。
