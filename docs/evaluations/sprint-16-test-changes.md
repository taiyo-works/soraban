### 16-B で画面の長さの上限に収めた方法（K-10）

上限は下げも上げもしていない。文字を 14px・本文を 16px・押す部品を 48px にしたことで、公開の `/` と運航管理の長い画面が上限を超えたので、**行の高さ・字間・余白・項目名の列幅**だけで収めた（構成・部品の形・色・文言は変えていない）。主な調整:

### 16-B で実行環境に気づいたこと

- `next build` が、Google Fonts の取得（`next/font/google`）で `next/font/google queries have exactly one entry` と出て失敗することがあった（同じコードの再実行で成功）。ネットワークの揺れ。
- `html` に `scroll-behavior: smooth` があるため、`scrollIntoView()` 直後に位置を測ると、スクロールが終わる前の値になる。`expectTextZoom` は `behavior: "instant"` を指定している。
