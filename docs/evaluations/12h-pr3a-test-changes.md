## D. 契約と食い違った点

- **Q-3「`/` で左メニューは判定が現在地」**：`/`（公開の判定画面）には左メニューがない（ログイン済みの下メニューと帯だけ。PR ② のまま）。PC の `/` で左メニューを出すには `/` の構造を変える必要があり、`/` を悪化させない（Q-18a）方針と合わない。`currentNavKey("/")` は `verdict` のまま（単体試験で固定）で、下タブには該当がないので `aria-current` は付かない。左メニューの判定が現在地になるのは、判定の項目が左メニューに出る画面だけ（`/ops` 配下から `/` へ行った後は、`/` 自体にメニューがない）。
