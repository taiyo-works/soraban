## 3. 判定色の役割分担

橙は「押せる・今ここ」、判定色は「結果」。判定の印・塗りに橙は使わない。形と言葉を併用する（色だけで区別しない）。

| 判定 | 塗り／文字 | 形 | 検査値（塗りの上の文字） |
|---|---|---|---|
| 飛行不可 | `#A81D28`／白 | 角丸の四角に× | 7.31 |
| 要手続き | `#EDB800`＋2px の枠 `#6B5800`／墨 | 三角（!） | 8.35 |
| 手続き済み・情報 | `#262523`／`#F7F7F3` | 丸にチェック | 14.26 |
| 手続き不要 | `#225F36`／白 | 太い輪（○） | 7.61 |
| 判定不能 | 白＋点線の枠 `#4F5762`／`#4F5762` | 点線の四角に？ | 7.31 |

期限・状態の札（ホームの「近づく期限」など）は判定色を使わない。期限切れ＝墨の面に白文字＋「！」、近い＝明るい橙＋墨文字。判定の語（要手続きなど）と混同させないため。

## 4. 挿絵の使いどころと禁止場所

- **使う**：判定画面のトップ（`/`）のヒーローだけ。丘 3 層・雲・日の出・ドローンの線画。高さはスマホ 232px、PC 320px（上限 240／320）。入力と結論が最初の画面に入ること。
- **使わない**：判定の結果の領域、運航管理（ホーム・計画・日誌・登録）、現場モード、PDF、エラーと空の状態（空の状態の小さなドローンは別途検討）、文字の読みやすさを損なう位置（文字は挿絵の淡い空の上に置き、ヒーローの丘の上には置かない。PC のチップは丘にかかるため白地にしてある）。
- 等高線は地図と見出しの飾りに限り、橙の `--sb-contour`。挿絵は `aria-hidden`、情報を持たせない。

## 9. 暗い表示（OS の暗い設定。2026-10-26 追加）

のりさん承認済みの決定：暗は `/` を v2 に載せる実装 PR（② ）の前に、文書とトークンと検査だけで定義する。今の公開の `/` は暗に対応しているので、v2 で暗が未定義だと後退になるため。値は `tokens-v2/soraban-tokens-v2.css` の末尾近く、見本は `warm-final/dark/`（`overview-dark.png`）。`apps/web` は変えていない。

### 9.1 考え方（5 つ）

1. **明の反転ではなく、別の組。** 地は純黒にせず温かい黒の 3 層（`#121110`／`#1B1A18`／`#252421`）。文字は紙の白を少し落とした `#F1EEE7`。
2. **橙は暗でも主役。** 橙 3 種と、橙の面に載せる墨の文字（`--sb-on-orange` `#262523`）は明と同じ値。暗の地の上では橙が 8.09:1 になり、明よりよく目立つ。
3. **面の差は輪郭で補う。** 暗は 3 層の明るさの差が小さいので、影（ぼかし）は使わず、ブロックに 1px の輪郭（`--sb-shadow: 0 0 0 1px #3A3834`）を付ける。
4. **判定は「明るい塗り＋暗い文字」に反転。** 形（×・△・丸にチェック・太い輪・点線に？）と言葉は明と同じ。橙とは別系統のまま（赤は桃寄りの `#F4797F`、琥珀 `#E6C64A`、淡い灰青、淡い緑、地色に点線）。
5. **現場の暗は 7:1。** 地をさらに深く（`#141312`／`#1F1E1B`／`#0A0A09`）、文字を `#F8F6F1` 以上に。陰影なし・動きなし・64px は明の現場と同じ。

### 9.2 面構成の決定（未決 1 の答え）

**3 層のまま。** 白・オフホワイト・ベージュの交互は v2 の骨格なので、暗でも帯を 3 色で交互にする。序列は `sunken ＜ base ＜ surface`（くぼみは深く、面は地より明るい）。ブロックは帯と別の層にする（明の「帯と逆の明るさ」は、暗では「隣り合う層と違う層」と読み替える。CSS の `.band-white .block { background: surface }` などの規則は変えずに、トークンの値だけで成り立つ）。層の差は 1.1〜1.3 倍と小さいので、ブロックの輪郭（1px）と、帯の境の明るさの段差で見分ける。2 色に減らすと、明と構造が変わり、帯の交互の効果が消えるため採らない。

### 9.4 ピルボタン（反転の考え方）

右端の丸は「墨の丸＋白い矢印」を、**暗では「明るい丸＋墨の矢印」に反転**する（`--sb-on-dot` が `#FFFFFF` から `#1B1A18` に変わり、丸の色は ink なので明るくなる。丸の上の矢印 15.0〜16.1）。ただし**橙の面の上では反転しない**：主ボタン（橙）は明暗とも「墨の丸＋白い矢印」（`--sb-on-orange` と `--sb-on-orange-fg`。橙の面は暗でも橙のため）、ホバーで橙が明るくなり丸が白に、矢印が墨になる動きも明と同じ。副ボタンは地より明るい面（`--sb-control`）に 1px の rule 縁、ホバーで丸が橙になり矢印は墨。番号・行の矢印・利用者アイコンの丸も ink（暗は明るい丸）で、中の文字は `--sb-on-dot`。ピルの矢印の入れ替え（動き）は暗でも同じ。

### 9.5 挿絵（トップだけ）

暗でも挿絵は判定のトップだけ。昼の景色を夜に置き換え、**空は暗い青緑**（`--sb-art-sky #1F2A2D`、地平線側 `--sb-art-sky-low #3A2B1E`）、**丘は茶（`#6F4526`）と深い青緑（`#1A5559`）**、手前の丘は暗の base（ページと地続き）。日の出の橙の円（橙のまま）、雲・ドローン・航跡・丘の等高線の線は `--sb-art-line #D3CFC5`（明るい線）、雲の面は `#34322F`。文字は空の上にだけ置く（空の上の本文 12.7、第二の文字 9.46）。挿絵は `aria-hidden` のまま情報を持たせない。見出し背後の大きな数字は橙 .16（装飾）。

### 9.6 影・輪郭・地図タイル

- **影**：暗では使わない。ブロックと端末の枠は 1px の輪郭（`#3A3834`）で分ける。現場は明と同じく none（罫 1.5px に置き換え）。
- **押せる部品の縁**は edge（暗 5.26〜6.39）。区切りの rule は 1.76:1 のまま区切り専用。
- **地図タイル**（国土地理院の淡色）は暗にしない。色（DID の斜線・水域・道路）で意味を持つので反転しない。眩しさだけ `--sb-tile-filter: brightness(.8)`（タイルの層だけに掛ける案。見本は SVG 全体に掛けた）で抑える。地図の上の印・文字は地図用の固定色（墨 `#262523`）で、暗の ink にしない。凡例（チップ内の見本）は地図と同じ明るい下地に載せる。**実機のまぶしさは未確認**（契約 Q-23・§11 の 7）。

### 9.7 判定色（暗）

橙とは別系統のまま、形と言葉を併用。**暗では塗りを明るくし、その上の文字を暗い色（`#1B1A18`）にする**。明では塗りが暗く文字が白だったので、色の役割は同じで明暗が逆。地（3 層）の上の塗りは 5.8 以上あり、枠なしで印の輪郭が地から離れる。
