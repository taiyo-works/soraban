# そらばん デザインシステム v2（草案）

2026-10-25。のりさんが選んだ「A（角を少しだけ丸める）を土台に、C の挿絵（丘と雲）をトップ画面だけに足す」案の土台を、v1（`docs/design/design-system.md`）との差分で書く。**草案。`apps/web` には入れていない。** 見た目の見本は `docs/design/warm-final/`、値は `docs/design/tokens-v2/soraban-tokens-v2.css`、検査は `docs/design/tokens-v2/check-contrast-v2.mjs`（112 件と寸法・動きを検査、0 件失敗）。

配色は FINESYSTEM（fg-finesystem.co.jp）準拠：橙 `#F89B48` が主役、白とオフホワイトを交互、ピルボタン＋右端の墨の丸と矢印、角丸 16/8/4、影は `0 0 24px` に黒 10% だけ。

## 3. 判定色の役割分担

橙は「押せる・今ここ」、判定色は「結果」。判定の印・塗りに橙は使わない。形と言葉を併用する（色だけで区別しない）。

| 判定 | 塗り／文字 | 形 | 検査値（塗りの上の文字） |
|---|---|---|---|
| 飛行不可 | `#A81D28`／白 | 角丸の四角に× | 7.31 |
| 要手続き | `#EDB800`＋2px の枠 `#6B5800`／墨 | 三角（!） | 8.35 |
| 手続き済み・情報 | `#262523`／`#F7F7F3` | 丸にチェック | 14.26 |
| 手続き不要 | `#225F36`／白 | 太い輪（○） | 7.61 |
| 判定不能 | 白＋点線の枠 `#4F5762`／`#4F5762` | 点線の四角に？ | 7.31 |

期限・状態の札（ホームの「近づく期限」など）は判定色を使わない。期限切れ＝墨の面に白文字＋「！」、近い＝明るい橙＋墨文字。判定の語（要手続きなど）と混同させないため。

## 4. 挿絵の使いどころと禁止場所

- **使う**：判定画面のトップ（`/`）のヒーローだけ。丘 3 層・雲・日の出・ドローンの線画。高さはスマホ 232px、PC 320px（上限 240／320）。入力と結論が最初の画面に入ること。
- **使わない**：判定の結果の領域、運航管理（ホーム・計画・日誌・登録）、現場モード、PDF、エラーと空の状態（空の状態の小さなドローンは別途検討）、文字の読みやすさを損なう位置（文字は挿絵の淡い空の上に置き、ヒーローの丘の上には置かない。PC のチップは丘にかかるため白地にしてある）。
- 等高線は地図と見出しの飾りに限り、橙の `--sb-contour`。挿絵は `aria-hidden`、情報を持たせない。

## 5. 現場モード（`data-mode="field"`）

v1 の方針を維持：文字 7:1、押す部品 56px、主ボタンとチェック行 64px、陰影なし（影を罫 1.5px に置き換え）、印の枠 2.5px、文字 24／18／14px、動き 0。v2 での差：ピルとチェック枠は丸め（行は 16、枠は 4）を保つが、矢印の入れ替えは止め、`ink-2/ink-3/ph/edge/判定の文字色` を濃くする（値は tokens-v2 の field ブロック）。橙の面（主ボタン・現在の段）はそのまま使える（墨の文字 7.13:1）。
