# そらばん デザインシステム

2026-10-25 版（v1）。この文書が唯一の正。値の実体は `docs/design/tokens/soraban-tokens.css`、検査は `docs/design/tokens/check-contrast.mjs`、全体の見本は `docs/design/system-sheet.png`。アプリのソースにはまだ取り込んでいない（移行は §12）。見本の元は `docs/design/tokens/sheet/`（`node build.mjs` で HTML、`node shoot.mjs 出力.png` で画像。Chromium は `/opt/pw-browsers`）。

## 1. 原則

1. PC もスマホも仕様は 1 本。部品は同じものを、サイズだけ変えて使う。変えるのは配置と密度だけ。
2. 地は生成り、文字は墨、線は銅。橙は面にだけ使う。色は判定のためにとっておく。
3. ブロックは直角。押せる部品だけ 3px。丸は許可リストの小さな操作部品だけ。
4. 判定は色だけで伝えない。形と文言を必ず添える。青は使わない。
5. 現場では動かさず、陰影も出さない。事務所と入口だけ、ゆっくり動かす。

## 3. 色

通常は文字 4.5:1・非文字 3:1、現場は文字 7:1・非文字 4.5:1 を下限にする。判定の塗りの上の白文字は、通常も 7:1。

### 3.1 使い分け

| 色 | 使う所 | 使わない所 |
|---|---|---|
| 地・面・くぼみ | 地はページ、面はパネル、くぼみは入力欄と表の見出し | — |
| 墨（文字） | 本文・見出し。判定の「手続き済み・情報」もこの墨 | — |
| 第二の文字・注釈 | 補足と 12px の注釈。注釈も 4.5:1 以上 | 12px 未満にしない |
| 橙（面専用） | 主ボタン・CTA の塗り、橙の面（墨の文字を載せる） | 線・文字・リンク。生成りの上で 2.0:1 のため読めない |
| 銅（線と文字） | 見出しの短い線（26px×2px）、現在地の印、フォーカスの輪、リンク | 大きな塗り |
| 罫（約 1.6:1） | 区切り専用 | 押せる部品の境（境は「押せる部品の境」を使う） |
| 判定 5 段 | 判定の印・帯・チェック。形と文言を併用 | アクセントの代わり。判定の印の中にアクセントを使わない |
| 灰 | 無効、未確認、判定不能 | 注意を引きたい所 |
| 使わない | ピンク、紫、金茶、青（判定の混同を防ぐ） | — |

要手続きの琥珀は、地との差が 1.8:1 しかない。琥珀の塗りの印は、必ず 2px の濃い枠（`--sb-v-needs-fg`）で囲む。

### 3.2 判定 5 段

| 段 | 色の方向 | 形 | 文言（例） |
|---|---|---|---|
| 飛行不可 | 深紅寄りの赤 | 四角に× | 飛行不可 |
| 要手続き | 黄みの琥珀 | 三角（!） | 要手続き |
| 手続き済み・情報 | 墨（無彩色） | 中抜きの丸にチェック | 手続き済み |
| 手続き不要 | 緑 | 輪 | 手続き不要 |
| 判定不能 | 灰 | 点線の四角に？ | 判定不能 |

「手続き済み」は、ご本人が自分で手続きを済ませたという記録の表示で、このアプリが手続きを済ませたという意味にしない。

### 3.3 暗と現場

暗は全パレット共通の夜間用で、OS の設定で自動に切り替わる（手動切替は後回し）。現場は明・暗のどちらにも重ねられ、7:1 に寄せ、陰影を罫に置き換える。`data-mode="field"` を付けると現場になる。

| 最小 | 12px。現場は 14px。12px 未満は使わない |

## 7. レイアウト

| 項目 | PC（1024px〜） | スマホ・タブレット（〜1023px） |
|---|---|---|
| ナビ | 左メニュー 240px。「調べる」（ホーム・判定）／「飛ばす」（計画・日誌）／「登録」（機体・操縦者・設定） | 下タブ：ホーム・判定・計画・日誌＋右端の丸いハンバーガー（登録・設定など） |
| ペイン | 複数ペイン。一覧と詳細を並べる | 1 画面 1 目的。詳細は次の画面 |
| 最大幅 | 本文の領域は 1200px まで。文章の 1 行は全角 40 字 | 画面幅いっぱい、左右 16px の余白 |
| 主な操作 | 画面の右上または文末 | 親指の届く下半分。画面下の保存バー（長いフォームだけ） |
| 余白 | 4px 基準：4／8／12／16／24／32／48／64 | 同じ |

768〜1023px は下タブのまま、2 ペインにしてよい。主要な導線（ホーム・判定・計画・日誌・登録）はハンバーガーだけに隠さない。ハンバーガーに入れるのは登録・設定などの奥の入口。

**現場モード**：点検・日誌など、屋外で手袋のまま使う画面に使う。押す部品は 56px（重要な画面は 64px）、文字は 24／18／14px、動きなし、陰影なし（罫 1.5px）、コントラスト 7:1。入口と切り替えの方法は未決（末尾の表）。

## 8. 動き

| 種類 | 時間 | イージング | 使う所 |
|---|---|---|---|
| 押下の色 | 120ms | `cubic-bezier(0.2, 0.8, 0.2, 1)` | ボタンの押下 |
| 状態の切り替え | 200ms | 同上 | ホバー・フォーカス・開閉 |
| メニュー（ふわっと） | 420ms | `cubic-bezier(0.4, 0, 0.2, 1)` | 左メニューの開閉、ハンバーガーの先 |
| 下からせり上がる表示 | 800ms | 同上 | 入口で 1 回だけ。ページごとには出さない |
| 起動画面の拡大と色の膜 | 1000ms | 同上 | 初回の起動だけ（ロゴ＋等高線） |

- 禁止：ホバーで跳ねる・拡大する、すべての要素がスクロールで現れる、ループする動き、動画の背景、動きのライブラリ（GSAP 等）への依存、視差。
- 現場モードと `prefers-reduced-motion: reduce` では、すべて 0ms（トークンの値を 0 にするだけで、各部品の書き方は変えない）。
- 動きは CSS の `transition` と `animation` だけで作る。

## 9. アート要素

- 等高線の線画。アプリの `contour.ts`（高さの場にいくつかの丘と手の震えを足し、一定の高さごとに線を引く）をそのまま使う。外部の画像・他社の素材は使わない。
- 置く場所：ページ上部の余白、見出しの下の 1 本の線（`wobbleLine`。右端に標高の数字）、空の状態、起動画面（ロゴ＋等高線）、左メニューの下の余白。
- 置かない所：文字の背後。線の色は地の約 1.3 倍の濃さ（明）で、文字が線をまたいでも本文は 9:1 以上を保つ。均一なパターンの敷き詰めとグラデーションは使わない。
- 暗では線を地の約 1.1 倍まで薄くする（実測。夜間のまぶしさを避けるため）。現場モードでは数を減らす。

## 10. アクセシビリティと現場対応

| 観点 | 規則 |
|---|---|
| 片手 | 主な操作を画面の下半分に置く。下タブは親指の届く範囲 |
| 手袋 | 押す部品は 56px 以上（重要な画面 64px）、隣の部品との間隔 8px 以上 |
| 日差し | 現場は 7:1。色の差だけに頼らず、形・文言・枠線の種類を併用 |
| 色だけに頼らない | 判定の印は形と文言を併用。チェックは実線・塗り・点線で分ける |
| キーボード | すべての操作に届く。フォーカスは 2px の銅の輪で、背景に対して 3:1 以上（現場 4.5:1） |
| スマホの押下 | :hover と同じ変化を :active と :focus-visible にも付ける |
| 電波 | 入力は端末内に自動保存し、電波が戻ったら送る。送れていない件数と、最後に保存した時刻を画面に出す（現在の `field-outbox` の仕組みとどこまで合うかは未確認。段階 E で確認） |
| オフライン | 保存済みの点検・日誌は、電波がなくても開いて書き足せる |
| 動き | `prefers-reduced-motion` に従う。現場は常に 0 |
| 文言 | 「代行」「申請を代わりに行う」と読める表現を使わない。本人が入力し、本人の名義で提出する |

## 11. やらないこと

- AI らしい見た目：紫のグラデーション、ガラス風、発光する枠、同じ形のカードの敷き詰め、丸いアイコン＋見出し＋2 行説明の 3 つ並び、絵文字の見出し、すべての見出しに色帯。
- 他サイトの見た目を写さない。参考にした方向は「生成りの地、墨の文字、橙・銅のアクセント」だけで、配置・部品の形・文言・画像は独自のものにする。
- 他社のロゴ・画像・書体の見本を、そのままの形で持ち込まない。書体は Noto Sans JP と Manrope（どちらも SIL Open Font License）。
- 偽の数字、偽の口コミ、動かない部品での「高機能風」の演出。
- 採用しないもの（決定 11）：ピンクの CTA、橙の文字・リンク、境界 #C4C4C4 のみのボタン、運航管理の削除、背景番号の濃い使用。
- 申請の代行に読める文言。
