そらばん 画面見本（v3 ミニマル）

飛行計画の通報、飛行前・飛行後の点検、日誌と飛行時間の記録。スマホで開いて、実際に触って確かめてください。

見本の画面はすべて架空のデータです。通報の送信や保存は行いません。地図の範囲選択、点検の「異常なし／あり」、離陸・着陸の切り替えは動きます。

  1. 1今日
    今日の飛行と、次にやること。通報の状態が一目で分かる。
  2. 2通報の新規登録
    6 つの手順。最初は地図で範囲を選ぶ。頂点の移動・追加・削除、円、取り消し。
  3. 3通報の確認
    要確認の項目を先に。DIPS で出して、受付番号を記録する 2 段。
  4. 4飛行前点検
    項目ごとに異常なし／あり。未選択を一括で「異常なし」に。
  5. 5飛行中
    離陸・着陸の大きなボタンと経過時間。圏外の表示。
  6. 6飛行後点検
    飛行前と同じ部品。異常ありの項目だけ内容と写真。
  7. 7日誌・飛行時間
    飛行記録、飛行時間、総飛行時間。確定と訂正。
  8. 8機体の点検・整備
    機体ごとの点検と整備の記録。
  9. 9空・読み込み・エラー・シート
    部品の見本。ボトムシートは開けます。

見ていただきたい点

  • 画面は短く、一番大事なものが一番大きいか。
  • 橙は「次の 1 つの操作」と現在地の丸だけに絞った。少なすぎないか、足りているか。
  • 通報の手順は、1 手順 1 画面でよいか。
  • 離陸・着陸のボタンは、橙の面でよいか。
