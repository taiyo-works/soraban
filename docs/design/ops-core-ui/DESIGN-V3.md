# そらばん デザインシステム v3（ミニマル）

> 状態: 設計（2026-11-01、designer）。アプリのコードは変えていない。見本は `01`〜`09` の HTML と `tokens.css`（本書のトークンの実体）。
> v2（`README.md` §6）を一段磨いたもの。画面構成・導線・測定基準は維持。実測は `README.md` §8。
> 読み方: 【確認】は一次資料または見本で確かめたこと。【未確認】は一次資料を開けておらず、記憶または二次情報によるもの（断定しない）。

## 0. v3 の一言

**面と余白で階層を作り、線は細く、橙は「次の 1 つの操作」と「いまの位置」だけ。** 画面の主役は 1 つ（大きな数字か主ボタン）。飾りは足さず、引く。

v2 からの主な変更:

| 項目 | v2 | v3 | 理由 |
|---|---|---|---|
| 区切り | 墨の 2px の枠・罫が多い | 1px の細い罫 + 面（`--surface`）。押せる部品だけ 1.5px の縁か面 | 線の数を減らし、押せるものが際立つ |
| 見出し | 見出し上の橙の棒・下の太い罫 | 大きなタイトル（32px/700）。縮むヘッダー | 橙の用途を操作と現在地に絞る |
| 主ボタン | 橙の面 + 墨の縁 + 右端の黒い丸 | 橙の面 + 墨の文字 + 矢印。縁なし（現場のみ墨の縁 2.5px） | ミニマル。直射日光では縁で輪郭を補う |
| 次の飛行 | 墨の 2px 枠 + 角の丸 | `--surface` の面（角丸 28px）+ 小さな橙の点と「次の飛行」 | 枠を面に置き換える |
| 選択肢 | 枠で囲んだ 2 択 | 溝（`--surface-2`）の中で選んだ側が墨の面になるセグメント | 面で選択を示す。iOS / Material の分割ボタンと同じ読み方 |
| 重ねる面 | なし | ボトムシート（`<dialog>`）、半透明の固定バー | 確認と補助入力を同じ画面の上で行う |
| 動き | 160ms 1 種 | 2 種（状態の変化 160ms / 面の出入り 280ms） | シートと画面遷移のため |

## 2. 原則（ミニマル）

1. **一番大事なものを一番大きく。1 画面に主操作は 1 つ。** 主操作は橙の面。他は面（灰）か文字。
2. **線を減らし、面と余白で分ける。** 罫は 1px、色 `--rule`。カードを並べない。主ブロック（次の飛行・合計）だけ `--surface` の面。
3. **色は 5 つ**: 白（地）、墨（文字・選択）、橙（操作と現在地）、赤系（異常・取消）、灰（面・補助）。緑は文字に限る（`--ok`）。
4. **角丸は役割で 4 段**: 28（シート・主ブロック・離陸/着陸）/ 20（地図・大きな面）/ 14（ボタン・入力・セグメント）/ 8（小さな札）。999 は状態の札とチップだけ。
5. **影は 3 か所だけ**: シート、固定バー、地図の上の浮いた部品。ほかは付けない。
6. **グラデーション・装飾アイコン・橙の棒は使わない。**

## 3. タイポグラフィ

| 役 | サイズ / 太さ / 行間 | 用途 |
|---|---|---|
| 数字（大） | 52〜80px / 700 / 1.05、等幅数字 | 次の飛行の時刻、経過時間（現場 80px） |
| 大きなタイトル | 32px / 700 / 1.3、`palt` | 画面名。スクロールで上の帯の 16px/700 に縮む |
| 見出し | 18px / 700 / 1.4 | 節。下に細い罫 |
| 本文 | 16px（現場 18px）/ 400〜500 / 1.7 | |
| 補助 | 14px（現場 16px）/ 500 | 下限。これより小さくしない |
| 札 | 14px（現場 16px）/ 700 | 状態の札、ボタン内の補助 |

- 太さは 400 / 500 / 700 の 3 種類（800 は使わない。v2 の 800 を 700 に下げ、和文の字面を軽くする）。
- **フォント**: `"Noto Sans JP", "Hiragino Sans", "Yu Gothic UI", "Yu Gothic", Meiryo, system-ui, sans-serif`。実装は `next/font/google` で Noto Sans JP の**サブセットを自社配信**（400/500/700 の 3 本、`display: swap`、日本語は unicode-range で分割されるため初回の読み込みは必要な分だけ）。**圏外では Service Worker のキャッシュ（ビルド時に取り込み済みのフォントファイル）か、端末の和文ゴシックに落ちる**。字形が変わっても幅が大きく変わらないよう、行長は余裕を持たせる。外部の Google Fonts へ実行時に依存しない。見本は端末のフォントのみ（外部通信なし）。
- 時刻・時間・件数は `font-variant-numeric: tabular-nums`。単位は小さく別行か隣に置く。

## 6. 動き（2 種類まで）

1. **状態の変化 160ms**（`--dur`、`--ease`）: 色・開閉・帯の伸び・押下の縮み（0.97）。
2. **面の出入り 280ms**（`--dur-sheet`）: シートの出入り（`--spring` で軽く弾む）、画面遷移のクロスフェード（View Transitions、対応端末のみ）。

ループなし、視差なし、自動再生なし。`prefers-reduced-motion: reduce` と現場モードは 0ms。振動は確定操作のみで、対応端末だけ（画面の変化でもあわせて伝える）。

## 7. アクセシビリティ

- コントラスト: 文字は AA（4.5:1）以上。現場は 7:1。非文字（縁）は 3:1 以上（`--edge` 3.5:1）。橙の面の上は墨。
- タップ: 48px 以上（現場 56px 以上）、隣と 8px 以上。シート内のボタンも同じ。
- フォーカス: 墨の 3px アウトライン + 2px のオフセット。`dialog` は標準のフォーカストラップ。
- 色だけに頼らない: 状態は記号と文字。セグメントの選択は面の反転 + 記号。
- 構造: `main`・`nav` の landmark、見出し階層、`aria-current`、タイマーは `role="timer"`、保存・圏外は `role="status"`。
- 文字サイズ: 14px 未満を使わない。OS の文字サイズ設定への追随と 200% 拡大の崩れは**未測定**（実装時に確認）。
- 画面の読み上げ・実機の手袋・直射日光は**未検証**。

## 8. 実装メモ（Next.js + Tailwind v4）

- `tokens.css` の `:root` を `@theme` に写す。角丸は `rounded-sb-m`（14）など 4 段、色は `sb-*`。
- 縮むヘッダーは小さなクライアントコンポーネント（`IntersectionObserver`）。サーバーで描ける部分は描く。
- シートは `<dialog>` を使う（ライブラリを足さない）。閉じるときのアニメーションは `@starting-style` か `closing` クラスで。
- 固定バーの `backdrop-filter` は `@supports` で囲み、フォールバックは不透明の白。
- View Transitions は App Router で実験的な扱い。まず見送り、後で `@view-transition` の 1 行で足せる設計にしておく。
- 禁止語（完璧・保証・必ず・代行・代理・申請の代行や支援と読める語、通報不要・問題なしと読める語）は画面・文言に使わない。ダミーデータは架空。提供元は `docs/provider-info.md` の確認済みの値のみ（正式名称のみ）。
