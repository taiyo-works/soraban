そらばん デザインシステム

生成りの地、墨の文字、銅の線。ブロックは直角で、押せる部品だけ 3px。PC もスマホも同じ部品を使い、変えるのは配置と密度だけにする。

各色の数字は生成りの地または面に対する比。通常は文字 4.5:1・線 3:1、現場は 7:1・4.5:1。罫（1.6:1）と橙（2.0:1）は区切りと面だけに使い、押せる部品の境には使わない。

橙は面、銅は線と文字

線は 26px×2px。文字にするときは濃い銅で、リンクは下線つき。

使わない色　ピンク・紫・金茶（判定色と混ざる）。橙の文字・橙のリンク（生成りの上で 2.0:1 で読めない）。灰色の枠だけのボタン（#C4C4C4 は地に 1.6:1）。

動きとアート

事務所の PC と入口は豊かに、現場はゼロ。動画も外部ライブラリも使わない。
動き（時間は棒の長さ、1 秒 = 120px）
押下の色120ms 状態の切り替え200ms メニュー（ふわっと）420ms 下からせり上がる（1 回）800ms 起動画面の拡大と色の膜1000ms

イージングは出入りが cubic-bezier(0.2, 0.8, 0.2, 1)、メニューと膜が cubic-bezier(0.4, 0, 0.2, 1)。起動画面は初回だけ（ロゴと等高線）。現場モードと prefers-reduced-motion では全部 0ms。ホバーで跳ねる・拡大する動きは作らない。
