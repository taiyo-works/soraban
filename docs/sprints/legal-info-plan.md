### 1.4 未確認の項目を画面に載せない設計

- 提供元の表示は、**確認済みの項目だけを描く**（正式名称、所在地、電話番号）。未確認の項目は、**行ごと出さない**（空欄・「準備中」・「未定」・仮の値・ダミーの文字を出さない）。確認済みの項目（名称・所在地・電話・代表者・メール・受付時間）は載せてよい。確認が取れたら、定数ファイル（`provider-info` の 1 か所）に値を足すだけで、全ての場所（フッター・このアプリについて・規約・マニフェスト・PDF）に反映される。
- 値の出どころは **1 か所の定数**（`docs/provider-info.md` と一致する。値の変更は文書と定数を一緒に直す）。
- 検査: ①`provider-info` の定数が `docs/provider-info.md` の確認済みの値と一致する（単体テストが文書の表を読んで比べる）。②画面・マニフェスト・PDF に、未確認の項目（受付の曜日・祝日、法人番号、適格請求書発行事業者番号、色コード、ロゴの使用ルールに関わる語句・値）が出ない。「未定」「準備中」「TBD」「要記入」「xxx」「ダミー」「example」が表示文言に 0 件。③確認済みの項目が、`/`・`/ops` の全画面から 1 タップ以内で見られる。④電話番号の表示は連絡の目的の表記（`tel:` のリンクにするかは任意）。
- 問い合わせは、確認済みの電話・メール・受付時間（9:00〜17:00。曜日・祝日は載せない）だけを載せる。受付の曜日・祝日（U1）が確認できるまで、「平日のみ」などの推測を書かない。

## 3. ファクトチェックの手順

### 3.1 手順（法令・制度・DIPS の仕様・データの出典に関する記述すべて）

1. **一次資料で確認する**: e-Gov 法令検索（航空法、同施行規則、小型無人機等飛行禁止法、行政書士法、個人情報保護法、特定商取引法、消費者契約法、電気通信事業法など該当するもの）、国土交通省・航空局の公表ページ（教則、無人航空機の飛行に関する通達・要領、DIPS 関連）、DIPS の公式ドキュメント（ガイドライン 1.10 版。利用規約）、国土地理院の利用規約、国土数値情報の利用約款、OpenStreetMap のライセンス。二次資料（解説サイト、ユーザー提供の文章、民間の企業データサイト）は**根拠にしない**。
2. **台帳に残す**: 項目ごとに**確認日・出典 URL・確認者・確認の結果（一致／不一致／未確認）・次回の確認日**。既存の台帳を使う: データは `packages/regulations/data/sources.json`、制度の手続きは `procedures.json` の `sourceUrl`・`verifiedAt`、DIPS の仕様は `docs/references/dips-fpr-guideline-findings.md`（版・頁つき）。**文言（画面・規約）ごとの根拠の台帳**（`docs/legal/fact-ledger.md` 案。1 行 = 文言の ID・文言・根拠の出典・確認日・確認者・状態）を新設する。
3. **確認できないものは断定しない**: 画面に「※要再確認」を出すか、その文言を出さない。画面の「※要確認」の表示は既存（12b の対応表、判定の注記）。
4. **古さの警告**: 確認日から一定日数（案: 90 日。既存の「出典・確認日が古い項目（90 日超）」と同じ。`plan-stale-sources`）を過ぎた根拠に警告。
5. **確認者**: 開発側（generator）の確認は「一次資料を読んだ記録」にとどまる。**法的な評価は専門家**（§4）。

### 7.2 設計

- **現場で読める短さ**: 1 画面 = 1 話題。見出し・手順の番号・短い文。375×812 で 1 話題がスクロール 2 回以内。現場モードからは「困ったとき」へ 1 タップ。
- **検索**: 語の検索（クライアント側、全文は小さい）。用語から該当の説明へ。
- **圏外**: ヘルプの本文を先読みの対象にする（Sprint 15 の仕組み。小さい）。
- **PDF 版**: 当面は作らない（画面が正。更新が二重になる）。要るときは「印刷用の表示」で足りる。ユーザーに聞く（任意）。
- **更新の運用**: ヘルプの本文は**コードと同じリポジトリ**に Markdown で置き（`docs/help/*.md` または `apps/web/content/help/`）、ビルドで画面にする。制度の説明には出典と確認日を付け、§3 の台帳に載せる。変更は PR の対象で、禁止語の検査（§2.4）にかける。
- **スクリーンショット**: 画面のスクリーンショットは**使わない（既定）**。画面が変わるたび古くなり、テストデータの個人名が写る危険がある。代わりに、手順の文章と、小さな図（SVG の枠線の図）を使う。使う場合は、E2E で自動撮影し、テストデータの個人名が写らないことを確かめる（Sprint 16 のブランドの方針と合わせる）。
- **免責・規約へのリンク**: 取扱説明書の末尾と各話題に置く。

### 7.3 段階

第一段階の完了時に**最小版**（使い方の流れ、点検、地図、圏外、通報のしかた、サポート、このアプリについて）。以降に拡充（FAQ、用語集、お知らせ、検索）。

### 既存の質問への影響

- **Q-L18（外部データ）**: 提供元の規約を確認した。Open-Meteo の無料 API は**非商用のみ**（有償プランが商用）。気象庁は公共データ利用規約（第1.0版）準拠で、気象業務法第17条・第23条への注意喚起がある。地理院タイル・ハザードマップポータル・国土数値情報 A16 は、出典の明示で利用できる条件。聞く点は「誤り・遅れの責任の表示」と「出典・取得時刻の表示で足りるか」に絞れる。
- **Q-L19（期限アラート）**: (a) 技能証明の「更新の期限（満了の 1 か月前）」の数字は、施行規則第236条の57・教則第5版で裏付けられた。聞く点は、**例外（国外滞在者の期間前の申請、災害時の有効期間の延長）を知らない札の断定が許されるか、注記の文言、「6 月前から 1 月前まで」の暦の数え方（月末の丸め）、期限後の効果**に変わる。(b) 保険は、教則第5版が「強制保険はなく任意。25kg 以上・レベル 3.5 等では加入が求められる」、審査要領 4-3-1(19) が 25kg 以上の加入を基準に置く。条文上の一般的な義務は見つからなかった。「義務」と読ませない表示の可否は、引き続き聞く。(d) 許可の期間は審査要領 3-3（原則 3 か月以内、継続的な場合は 1 年が限度）。
- **Q-L20（緊急用務空域）**: **飛行前の確認は、施行規則第236条の71第4項に明文の義務**がある。公示は同条第2項（インターネットの利用その他の適切な方法）で、国土交通省のホームページと X。聞く点は「確認が義務」という書き方と「確認してください」のどちらが適切か、**自動で「該当なし」と出さない表示**、**許可があっても飛行できない（教則・公表ページの記述）ことの条文上の根拠**、DIPS 上の掲示の有無（航空局への確認）に変わる。
- **Q-L21（地図の注記）**: 淡色地図の出典表示は、地理院タイルの一覧ページの条件（「国土地理院」または「地理院タイル」＋一覧ページへのリンク）に現行の実装が沿う。聞く点は注記の文言のみ。
