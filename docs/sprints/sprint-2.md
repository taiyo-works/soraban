# Sprint 2: 期限カレンダー ＋ カテゴリー切り分け（II / III 切り分け）

> 親文書：`docs/spec.md`（§3.3 カテゴリー制度・§3.4 期限・§7 UI 構成・§11 要再確認）
> 前提：Sprint 1（診断ロジック・チェックリスト）が完了していること。

## 実装する機能

- **機能A：提出期限の逆算（開庁日計算）** — 飛行予定日の入力を受け、各手続きの提出期限を「飛行日 − 10 開庁日（土日祝除く）」で計算する。祝日は日本の国民の祝日に従う（spec §10-4 推奨＝内閣府公開データを静的同梱）。
- **機能B：期限カレンダー UI** — 計算した提出期限を手続きごとに日付で表示し、期限が近接／超過する場合にアラート色（North Star 信号色）で警告する。
- **機能C：カテゴリー切り分けバナー** — 「立入管理措置の有無」「第三者上空か」の入力から、カテゴリー（I / II相当 / III＝レベル4）を切り分け、結果セクション先頭に提示する。III は「一等無人航空機操縦士 ＋ 第一種機体認証が必須」を強調表示する。

## スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 飛行予定日を入力するフィールドが UI 上に存在し、日付を選択／入力できる。
- [ ] 飛行予定日に **2026-07-31（金）** を入れると、特定飛行に該当する手続きの提出期限が「飛行日 − 10 開庁日」で計算され、**土日祝を除いた具体的な日付**として表示される（手計算と一致すること。例として 2026-07-31 から 10 開庁日前を逆算した日付）。
- [ ] 開庁日計算が**土曜・日曜・日本の国民の祝日を除外**している（途中に祝日を含む期間で検証し、単純な 10 暦日前にならないことを確認できる）。
- [ ] 飛行予定日が未入力のときは、期限カレンダーが「飛行予定日を入力してください」と促し、誤った日付を出さない。
- [ ] 提出期限まで残り日数が少ない（または過ぎている）場合、当該手続きにアラート色（amber/red）が付く。
- [ ] 「立入管理措置の有無」「第三者上空か」を入力する UI が存在し、操作できる。
- [ ] **第三者上空（立入管理措置なし）** を選ぶと、結果セクション先頭のバナーに「カテゴリー III／レベル4」相当と「一等無人航空機操縦士 ＋ 第一種機体認証が必須」が明示される。
- [ ] 立入管理措置あり・第三者上空でない場合は「カテゴリー II（申請で済む領域）」相当が提示される。
- [ ] 特定飛行に非該当（フラグなし・100g 未満等）の場合は「カテゴリー I（手続き不要）」相当が提示される。
- [ ] カテゴリー切り分けバナーに出典（`https://www.mlit.go.jp/koku/level4/` 等）が併記されている。
- [ ] IIA／IIB の表示名が、未確認（spec §11-D）であることを踏まえ「相当」表記またはツールチップ等で断りが入っている（確定的に正式名称と断定していない）。
- [ ] 期限・カテゴリーいずれも、要再確認事項（spec §11）を確定事実として表示していない。
- [ ] Sprint 1 のチェックリスト・既存フローにリグレッションがない。
