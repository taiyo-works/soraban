# Sprint 10a: 公開面の整備（トップ画面・PDF の表示の見直し）

> 親文書：`docs/spec.md` §13.6（2026-10-19 差し込み）／ `docs/00_NORTH_STAR.md` §0.1.8
> 期間：数日（差し込み）。DIPS 2.0 API の利用申請で本番の URL を記載する前に終える。
> 前提：他のスプリントに依存しない。DB・外部 API を使わない。判定ロジックと証跡 ID の計算は変えない。
> ※ Next.js は破壊的変更を含むため、実装前に `node_modules/next/dist/docs/` を参照（`apps/web/AGENTS.md`）。
> ※ 並行するスプリントも `regulation-checker.tsx` を触る可能性がある。本スプリントの変更は文言・コメント・ラベルに限り、差分を小さく保つ。

## 目的と位置付け

本番のトップ画面（`apps/web/src/app/page.tsx`）は、見出し・メタ表示・本文・ロードマップ・技術スタックが社内の開発メモの性格のまま公開されている。DIPS 2.0 API の利用申請などで国土交通省の担当者の目に触れる可能性があるため、サービスの顔として見直す（ユーザー承認済み、2026-10-19）。

特許は出願しておらず、当面出願しない（North Star §0.1.8）。出願していない発明について「出願中」などと表示することは特許法の虚偽表示に当たるため、特許に関する表示・記述はすべて外し、類する表示も置かない。

## 実装する機能

- **A. トップ画面の見出し**
  - 見出しは名前と目的を一行で示す：「そらばん」と「ドローン飛行の可否判定と運航管理」。（2026-10-19 変更：最終目標が全国展開になったため、見出し・title・description から地域を外し、地域は対象地域で示す。ユーザーの方針）
  - 本文は 1〜2 文で、現在できることを事実だけで書く。例：「地点を指定すると、航空法（人口集中地区・空港等周辺）、小型無人機等飛行禁止法、鳥取県・島根県と県内市町村の条例に照らした判定を、データの出典と確認日とともに表示します。」
  - メタ表示（`dl`）は次の 3 項目に置き換える（`data-testid="site-facts"`）：
    - 運営者：フューチャーテック株式会社
    - 利用の範囲：現在は社内での試験運用中
    - 対象地域：現在は鳥取県・島根県（自治体の収録数は `COVERAGE_SUMMARY` から出す）
  - 見出し下の注記（盲点・特許コア・registry の説明）は削除する。
  - 判定は参考情報で、最終確認は国土交通省・警察・自治体で行う旨を、見出しの近く（スクロールせずに見える位置）に 1 文で置く（`data-testid="site-disclaimer"`）。例：「判定結果は参考情報です。飛行の可否は、国土交通省（DIPS 2.0）・警察・各自治体で最終確認してください。」
  - 見た目は現在の紙面調（罫線・書体・余白）を活かし、装飾の少ないサービスらしい見出しにする。英字の飾り見出し（`Aerial Compliance Atlas`、製図の脇書き `Subject — UAV / aerial unit` など）は減らす方向で designer が判断する。ドローン線画は残してよい。
- **B. 削除する節**

## 文言の整合

- 名前と目的「そらばん — ドローン飛行の可否判定と運航管理」は、DIPS 2.0 API の利用申請書の「サービス概要」欄（そらばん：判定と運航管理）と食い違わないようにする。申請書と画面で別の言い回しを作らない。
- 運航管理（機体・操縦者・飛行記録など）は Sprint 10 以降で作る。画面では「運航管理」を目的として示すが、提供中の機能として個別の画面名や件数を書かない。予定の日付も書かない。
- 誇張・比較の表現（「全社の盲点」「唯一」「業界初」など）を置かない。
