# Sprint 3: 書類ドラフト / DIPS プリフィル ＋ 束ね PDF

> 親文書：`docs/spec.md`（§1.2 ゴール④⑤⑥・§6 データモデル PrefillField・§7 UI 構成・§9 技術スタック）
> 前提：Sprint 1・2 が完了していること。DRS と DIPS2.0 を別導線として案内する方針を維持。

## 実装する機能

- **機能A：DIPS 入力プリフィル表** — 診断結果と入力値から、DIPS の入力欄に対応する値（`PrefillField`）を表で生成。各行に「DIPS のどの入力欄か（ラベル）」「コピペ用の値」「値の出所」を表示し、行ごとにコピペできる。
- **機能B：独自飛行マニュアル等のドラフト生成** — 飛行方法・機体・運航条件に応じた独自飛行マニュアルの骨子ドラフトをテキストで生成・表示する（標準マニュアル 01/02 の本文転載はせず、選択と独自テンプレ骨子に留める：spec §10-5）。
- **機能C：束ね PDF 出力** — カテゴリー切り分け・必要手続きチェックリスト・期限カレンダー・プリフィル表・書類ドラフトを 1 つの PDF として出力する（既存 `regulation-pdf.tsx` の作法＝`@react-pdf/renderer`・Noto Sans JP・デザイントークン整合・動的 import）。

## スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 米子市役所 ＋ 夜間 ＋ 目視外で診断後、画面に **DIPS 入力プリフィル表**が表示され、各行に「DIPS 入力欄ラベル」「コピペ用の値」「値の出所」の 3 情報が揃っている。
- [ ] プリフィル表の各行に**コピペボタン**があり、クリックするとクリップボードに当該値がコピーされる（コピー成功のフィードバックが表示される）。
- [ ] プリフィル表に、座標・住所・飛行方法（夜間／目視外等）・機体重量など、入力／判定から得た値が反映されている（空のダミーではない）。
- [ ] **独自飛行マニュアルのドラフト**が生成・表示され、選択中の飛行方法（夜間・目視外等）に対応した記述が含まれる。標準マニュアル本文の転載をしていない。
- [ ] 「標準マニュアル（01／02）を使う」か「独自マニュアルを作る」かを選べる UI があり、選択に応じて出力が変わる。
- [ ] **束ね PDF 出力ボタン**があり、クリックすると単一 PDF がダウンロードされる。PDF にカテゴリー切り分け・必要手続きチェックリスト・期限カレンダー・プリフィル表・書類ドラフトの各セクションが含まれる。
- [ ] PDF 内で日本語が文字化けせず表示される（Noto Sans JP 登録が効いている）。
- [ ] PDF・画面ともに、DRS（機体登録）と DIPS2.0（許可承認）の URL が**別導線として区別**して記載されている。
- [ ] PDF に免責文と各手続きの出典 URL が含まれている。
- [ ] PDF のファイル名・メタに `evidenceId`（または相当の証跡 ID）が含まれ、いつのロジックの診断かを同定できる。
- [ ] 既存の単発判定 PDF（`regulation-pdf.tsx`）が引き続き動作し、リグレッションがない。
