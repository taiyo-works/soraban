### 3.2 橙の使い分け（契約。値が決まった後も適用）

コントラストは、現在の値で計算した【確認・計算】: 橙 `#F89B48` と白 **2.15:1**、橙の面の上の墨 `#262523` **7.13:1**、銅 `#B4541F` と白 **4.97:1**（オフホワイト `#F7F7F3` の上で 4.62:1）、`#E99347` と白 2.41:1、`#FFC189` と白 1.59:1。

| 用途 | ルール |
|---|---|
| **主ボタンの橙（操作の色）** | 橙の面＋墨の文字（7:1 以上）＋墨の縁（面だけでは白の地との境界が 3:1 に満たないため）。右端の墨の丸と矢印（既存のデザイン）。1 画面に主ボタンは 1 つ（現場は主操作 1 つ） |
| **あしらいの橙（装飾）** | 面積は 1 画面の **5% 以下**を目安（見出しの短い線、区切りの細い線、小さな印、アイコンの差し色、空の状態の挿絵）。**情報を持たせない**（色だけで意味を伝えない）。淡い橙の面（`--sb-orange` の 10〜15% など）は、背景の差別化に限り、文字の地にする場合は文字の比を満たす |
| **文字に使う橙** | **橙 `#F89B48` を白の地の文字に使わない**（2.15:1 で不足）。文字・細い線に橙系を使うときは**濃い橙**（銅 `#B4541F` 相当。白の上で 4.5:1 以上）か墨を使う。Sprint 16 の T-6（橙の文字が 0）を維持。濃い橙の値は、公式のオレンジが決まった後に**同じ色相で明度を下げて**決め、比を計算して台帳に残す |
| **橙の面の上の文字** | 墨（7:1 以上）。白は使わない |
| **判定色（赤・黄・緑・墨）との混同の回避** | 判定の黄（要手続き）は橙と近い。**判定の塗りは橙系にしない**。橙のあしらいは、判定の結果の近く（結論の札・判定の行）に置かない。判定は**形（×・△・丸にチェック・輪・点線の？）と言葉**を必ず併用（既存）。橙の主ボタンと判定の黄の色相差・明度差を見本で確かめ、色覚の模擬（Sprint 16 の S-3）で区別できること |
| **地図の上の橙** | 範囲（飛行エリア）の色に橙系を使う場合、判定のレイヤー（赤・黄）と混ざらないよう、範囲は線＋淡い塗りで、判定のレイヤーと形を変える（Sprint 19 U-5） |
| **暗の値** | Sprint 16 の決定のとおり当面は常に明るい表示 |

オレンジを軸に、**品のある統一**: 白〜ごく薄いグレーの地、墨の文字、橙は随所に**小さく・効かせて**使う。

### 4.1 画像の作り方の方針

`docs/HANDOFF.md`（11b: 「見出しの線画は、ユーザーが Adobe Firefly で生成した PNG に差し替え」）と Sprint 12g（「アイコン・コマンドパレット・シート・ポップオーバーは自作」。依存を増やさない）に従う: **アイコン・小さな図は SVG（自作。インライン）／大きな絵（トップの挿絵、OGP の絵）だけ Firefly（ユーザーが生成し、PNG を渡す。生成した画像の権利・利用条件は Adobe の規約を確認※要再確認）**。画像の容量は LCP の要素にしない（既存の方針: インライン SVG は画像要求 0 件）。他社の絵・ロゴの写しをしない。
