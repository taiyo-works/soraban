# Sprint 4: 免責 / 出典 / 法令正確性の作り込み ＋ 磨き込み（受け入れ統合）

> 親文書：`docs/spec.md`（§8 法令正確性・免責方針・§11 要再確認・§12 受け入れ基準）
> 前提：Sprint 1〜3 が完了していること。本スプリントは安全クリティカル要件の最終ゲートと統合受け入れ。
> ※ デザイン磨き込みは designer 工程、合否は evaluator がデザイン4基準で判定する（プロジェクト規約 §5）。

## 実装する機能

- **機能A：法令正確性ガード（要再確認の明示分離）** — spec §11 の要再確認事項（25kg 保険義務化・300m/1000m・標準処理期間・IIA/IIB 呼称）を、確定事実と視覚的・文言的に分離して扱う（「※要再確認」表示または非表示）。確定事実には必ず出典 URL を併記する。
- **機能B：DRS / DIPS2.0 別導線の徹底と免責の全面表示** — 機体登録（DRS）と許可承認（DIPS2.0）の導線・URL を全画面・全 PDF で明確に分離。免責（「本機能は補助であり最終確認は DIPS／航空局で」）を全画面・全 PDF に表示。
- **機能C：統合受け入れ（spec §12 シナリオ）の通し検証と磨き込み** — North Star §4 デザイン4原則・WCAG 2.2 AA を踏まえた最終調整。AIスロップの排除。

## スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

### 法令正確性・免責

- [ ] （Sprint 6 注記：日付は 2025/10/1 が正しく、確証取得済みのため Sprint 6 で手続き化）「総重量 25kg 以上は 2026/10/1 以降の申請分から保険必須」が**確定事実として表示されていない**（非表示、または「※要再確認」明示のいずれか）。
- [ ] （Sprint 7 注記：2026-07-14 施行の改正でおおむね 1,000m に変わったため、Sprint 7 で置き換える）小型無人機等飛行禁止法のバッファが **300m** で扱われている（1000m と表示しない）。既存 `MIHO_REG`（300m 実装）と矛盾しない。
- [ ] 標準処理期間について、「10 開庁日以上前」を計算根拠としつつ「目安」である旨が明示されている（確定的な法定処理期間として断定していない）。
- [ ] IIA／IIB の呼称が「相当」表記またはツールチップ等で未確認である旨を断っている。
- [ ] 確定事実として表示している各手続き・カテゴリー・期限に、**出典 URL と法的根拠**が併記されている。
- [ ] 制度データ（`packages/regulations/data/...`）の各手続きレコードに、改正レビュー用の検証日メタ（`verifiedAt` 相当）が入っている。

### 別導線・免責の全面表示

- [ ] **機体登録は DRS（`https://www.dips-reg.mlit.go.jp/drs/`）、許可承認は DIPS2.0（`https://www.ossportal.dips.mlit.go.jp/`）** として、URL とラベルが画面・PDF の両方で明確に区別されている。
- [ ] 免責文が**全画面**（入力前・結果表示・チェックリスト・プリフィル）と**全 PDF** に表示されている。
- [ ] 自動申請・自動入力・DIPS への自動操作の導線が存在しない（コピペ／PDF のみ）。

### 統合受け入れ（spec §12 を通しで検証）

- [ ] **米子市役所 ＋ 夜間 ＋ 目視外**で、必要手続きに「飛行許可（DID）」「飛行承認（夜間）」「飛行承認（目視外）」「機体登録（DRS）」が出力され、飛行予定日を入れると提出期限が飛行日 − 10 開庁日で表示される（end-to-end で 1 操作列として再現可能）。
- [ ] **100g 未満**を入力すると航空法系手続きが消える。
- [ ] **第三者上空**を選ぶと「カテゴリー III／レベル4・一等 ＋ 第一種機体認証必須」の切り分けが先頭に出る。
- [ ] 束ね PDF が 1 ファイルで出力され、全セクション・免責・出典・別導線を含む。

### デザイン（North Star §4・WCAG 2.2 AA）

- [ ] モノクロ ＋ 単一アクセント（藍）＋ 信号 3 色のみで、装飾色が増えていない。
- [ ] 信号・アラートが色だけに依存せず、色 ＋ アイコン ＋ テキストラベルの三重符号化になっている。
- [ ] キーボードのみで主要機能（飛行方法選択・飛行予定日入力・コピペ・PDF 出力）に到達できる。

- [ ] AIスロップ兆候（意味のない反復・テンプレ然とした余白崩れ・無根拠の装飾）が見られない。
