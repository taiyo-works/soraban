# 一次資料の確認台帳（fact-checker）

- 目的: 画面・文書の事実の主張を、一次資料で確認した記録。取得できたものだけを「確認済み」とし、できないものは「※要再確認」とする。
- 機械可読の台帳 `packages/regulations/data/sources.json` は、確認日を変えると証跡 ID が変わるため **編集していない**。本ファイルは、その補助の記録（人が読む用）。
- 運用の決まり（2026-11-25、16-H2 の再レビュー N-g）: `sources.json` のデータセットの版・提供元・URL を変えるときは、確認日（`verifiedAt`）も必ず更新する。計画の判定の画面は、保存した確認日と台帳の確認日が一致するときだけ台帳の版・提供元・URL を出すため、確認日を変えずに版だけ変えると、判定に使っていない版を表示してしまう。
- 法令・教則・審査要領の文章は丸写しせず、条の構成と要旨だけを書く。法的な結論は書かない。
- 確認者はすべて fact-checker（Claude）。取得は 2026-11-22、すべて HTTP 200 で本文を取得できた（個別に注記のあるものを除く）。
