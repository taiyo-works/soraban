## 調査で一致した内容（※要確認）

### 根拠

- 報告要領は、航空法第132条の90・航空法施行規則第236条の85、航空法第132条の91・同規則第236条の86・第236条の87 に基づくとされる。**条番号は二次情報**（原本・e-Gov と未照合。U5・U17）。画面・コードには書かない。

### 事故と重大インシデント（例）

| 区分 | 例 |
|---|---|
| 事故 | 無人航空機による人の死傷（重傷以上）／第三者の物件の損壊／航空機との衝突・接触 |
| 重大インシデント | 無人航空機による人の負傷（軽傷）／制御不能／飛行中の発火／航空機との衝突・接触のおそれ |

- **事故も重大インシデントも、国土交通大臣への報告の対象**とされる。
- 単純な操縦の誤りは「制御不能」に当たらないが、別の類型に当たりうる、という解釈が国土交通省の資料にあるとされる。
- 機体の紛失の扱いは、資料により記述が分かれる（※要確認）。
- 軽傷・重傷の線引きの定義は確認していない。

### 義務

- 事故等が起きたときは、直ちに飛行を中止し、負傷者を救護し、危険を防止する措置をとるとされる。
- 国土交通大臣へ報告する。報告しない・虚偽の報告には罰金（30 万円以下とされる）。**罰則の額は二次情報**で、アプリには出さない。

### 報告の方法

- DIPS 2.0 の「事故等の報告」から、速やかに報告するとされる。
- DIPS 2.0 を使えないやむを得ない場合は、電子メール（様式あり）で報告するとされる。様式・宛先は未確認。
- 「速やかに」以外の数値の期限は、この調査では見つかっていない。アプリは期限の語・数値を出さない（12e の設計 A）。

### 報告事項（規則第236条の85 の各号とされる）

操縦者の氏名・所属、技能証明書番号、日時・場所、許可・承認の日付と番号、出発地・到着予定地、飛行の目的・概要、事故の概要、人の死傷・物件の損壊の概要、機体の損壊の概要など。

- 一覧は二次情報で、各号の全体・順序・書き方は未確認。12e では使わない。報告の下書き（報告事項に沿って事実を整理しコピーする機能）は、U17 で照合したあと別の契約（12e-2 の候補）で扱う。

### DIPS 2.0 の API

- DIPS 2.0 の API に、事故の報告の API はない。FPR ガイドライン 1.10 版が定める API は 3 つだけ（`docs/references/dips-fpr-guideline-findings.md`）。将来 API の連携ができても、事故の報告は利用者が DIPS 2.0 の画面で行う前提になる。
